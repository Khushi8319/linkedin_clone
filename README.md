# LinkedIn Clone

## Overview

A responsive LinkedIn-inspired frontend application built using React and Vite. This project replicates the core user interface and functionality of LinkedIn using dummy data and client-side state management.

## Features

- User login interface
- Protected routes
- Home feed with posts and interactions
- Create and publish new posts
- Profile page with user information
- My Network page with connection suggestions
- Responsive design for mobile, tablet, and desktop

## Tech Stack

- Frontend: React.js, Vite, React Router DOM, Tailwind CSS, React Icons
- State Management: Context API
- Version Control: Git & GitHub
- Deployment: Netlify

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Khushi8319/linkedin_clone.git
```

### 2. Navigate to the project folder

```bash
cd linkedin_clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

```bash
npm run dev
```
